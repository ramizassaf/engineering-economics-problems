الملحق L — حلول مسائل الفصل الرابع

الحلول التالية محسوبة ببرنامج من نفس بنك الأسئلة الذي ولد نصوص المسائل. إذا حللت بالجداول قد يختلف جوابك في الخانة العشرية الأخيرة.

الجزء أ: أسئلة مفاهيم

4.1 هو النسبة التي تجعل القيمة الحالية لكل تدفقات المشروع صفرا.

4.2 لا. المعدل هو العائد على الرصيد الذي لم يسترد بعد في كل سنة. الرصيد يقل كل سنة حتى يصل إلى الصفر في نهاية العمر.

4.3 لأن المعدل نسبة لا تعكس حجم الاستثمار. البديل الأغلى قد يكون معدله أقل لكنه يضيف ثروة أكبر، إذا كان المال الإضافي فيه يكسب أكثر من الحد الأدنى للعائد.

4.4 هو معدل الفرق بين تدفقات بديلين: الاستثمار الإضافي مقابل الدخل أو التوفير الإضافي. إذا كان أعلى من الحد الأدنى للعائد نختار البديل الأغلى، وإلا نبقى على الأرخص.

4.5 لأن بدائل التكاليف ليس لها دخل، فكل تدفقاتها سالبة ولا توجد نسبة تجعل قيمتها الحالية صفرا. نحسب المعدل للفرق بين بديلين فقط، حيث التوفير يقابل الاستثمار الإضافي.

4.6 عندما تتغير إشارة التدفقات أكثر من مرة. مثال: منجم أو مكب نفايات يحتاج تكلفة كبيرة لإعادة تأهيل الموقع في نهاية عمره.

4.7 المعدل يفترض أن الدخل يعاد استثماره بنفس المعدل. المعدل المعدل ينقل الدخل إلى نهاية العمر بنسبة إعادة استثمار واقعية، غالبا الحد الأدنى للعائد.

4.8 نختار المشروع صاحب القيمة الحالية الأكبر عند 10%. تحت نقطة التقاطع يتفوق المشروع الذي منحناه أشد انحدارا، وهو غالبا الأكبر استثمارا أو الأبعد دخلا.

4.9 لأن المنافع تعود للمواطنين وليس للحكومة، فلا يوجد إيراد يحسب منه عائد للحكومة. النسبة تقارن ما يكسبه المجتمع بما تدفعه الحكومة.

4.10 أكبر. المقترض يدفع أقساطا محسوبة على كامل القرض، لكنه يستلم مبلغا أقل. المعدل الذي يساوي بين الأقساط والمبلغ المستلم أعلى من المعدل المعلن.

import numpy_financial as npf

def npv(i, flows):
    return sum(cf / (1 + i) ** t for t, cf in enumerate(flows))

def irr_bisect(flows, lo=0.0, hi=1.0):
    for _ in range(100):
        mid = (lo + hi) / 2
        if npv(mid, flows) > 0:
            lo = mid
        else:
            hi = mid
    return mid

import numpy_financial as npf

def incremental(alts, n, marr):
    alts = sorted(alts, key=lambda a: a[1])
    best = ("none", 0, 0)
    for alt in alts:
        dc, dr = alt[1] - best[1], alt[2] - best[2]
        r = npf.irr([-dc] + [dr] * n)
        print(alt[0], "vs", best[0], round(r, 4))
        if r >= marr:
            best = alt
    return best[0]
